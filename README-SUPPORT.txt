WRLDD VAULT — SUPPORT FILES

Upload these files into the SAME root folder as index.html in your GitHub repository.

Included:
- manifest.webmanifest — installable app settings
- icon-192.png and icon-512.png — home-screen/app icons
- sw.js — basic offline caching for files already visited/cached
- wallpapers.json — starting empty list for shared wallpaper entries
- .nojekyll — tells GitHub Pages not to process the site with Jekyll

Important:
1. These are supporting files, not a replacement for index.html.
2. The current app's owner uploads are local to the device; these files do not create secure shared publishing.
3. Offline availability is limited to files that the browser has successfully cached. First open the app while online.
4. This is an unofficial fan project and is not affiliated with Juice WRLD's estate, label, or rights holders.
